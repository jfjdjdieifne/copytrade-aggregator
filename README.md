# Copy-Trade Aggregator v2 — رادار إجماع المحترفين

> نظام يرصد متداولين محترفين **مستقلين** على منصات كريبتو مجانية، ويُصدر توصية فقط عندما يتفق اثنان أو أكثر منهم على نفس العملة ونفس الاتجاه بتقارب سعري وزمني ضيق.
>
> **يعمل بالكامل على Cloudflare مجاناً**: Python Worker + Cron + Workers AI + Durable Objects.

⚠️ **HYPOTHETICAL_ — كل ما يصدره النظام تحليل آلي وليس نصيحة مالية. لا يوجد تنفيذ صفقات.**

---

## الفكرة في سطر

> لا نتبع متداولاً واحداً. ننتظر حدثاً نادراً: **متداولان مستقلان، على منصتين مختلفتين، يفتحان نفس الصفقة في نفس الساعة بنفس السعر**. هذا هو الإجماع الذي يحمل معلومة حقيقية.

الفارق الجوهري عن «نسخ الصفقات» التقليدي:

| النسخ التقليدي | هذا النظام |
|---|---|
| يتبع متداولاً واحداً | يشترط **2+ مستقلين** |
| يقلّد كل صفقة | يُصدر **إشارة نادرة** فقط |
| ينخدع بنجوم الليدربورد | يفلتر بـ7 معايير ثبات حقيقية |
| ينسخ حتى التحوط | يحسب **صافي المركز** ويستبعد المتحوّط |
| يقيس النجاح بالكلام | يقيس **R الفعلي** بعد النشر |

## البنية

```
src/cta/
├── config.py         إعدادات مُتحقَّقة (env أو mapping أو binding object)
├── models.py         Position / TraderStats / Cluster / Signal  ← الوحدة الذرية Position لا fill
├── classifier.py     ★ إعادة بناء منحنى رأس المال + 7 معايير → ELITE/PROVEN/WATCH/REJECT
├── discovery.py      ★ 47k محفظة → 300 مرشح (فرز رخيص قبل الاستدعاءات الغالية)
├── convergence.py    ★ بوابات التقارب: تحوط، استقلالية، سعر، زمن، رافعة
├── confidence.py     ★ 5 مكوّنات = 100 نقطة قابلة للتفسير
├── plan.py           ★ ستوب/هدف من المصدر، ATR موسوم عند الغياب، تحقق اتجاه إلزامي
├── engine.py         منسّق: profile → scan → signal
├── outcomes.py       تتبّع أمامي: MFE/MAE/R لكل إشارة
├── ai.py             Workers AI + مُلقِّن عربي حتمي كبديل
├── bot.py            موجّه أوامر تلغرام + محادثة
├── telegram.py       إدخال/إخراج تلغرام (تقسيم رسائل، أزرار، webhook)
├── state.py          Store (Durable Object | Memory)
├── sources/          hyperliquid.py · dydx.py · gmx.py + rate limiter
├── demo.py           ★ عرض كامل بلا إنترنت (اختبار القبول)
├── runtime.py        الدوال المشتركة بين Worker وCLI
├── worker.py         توجيه HTTP + cron
└── durable_object.py RadarState (SQLite داخل DO)
```

### نقطة التصميم الأهم

`clearinghouseState` (مراكز أي محفظة) **وزنه 2** من 1,200 في الدقيقة، بينما `userFills` **وزنه ~20**.
لذلك: نستطلع المراكز للجميع كل دقيقة (25% من الميزانية)، ونجلب الصفقات **فقط للمحافظ التي تحرّكت**. هذا ما يجعل مراقبة 150 محفظة مجاناً ممكنة.

> الشريط في الأعلى صادق دائماً: 🟢 حيّ، أو 🟡 عرض تجريبي يشرح أن الأرقام محسوبة على بيانات تجريبية.
> لا يوجد رقم مُختلق في أي حالة — وعند غياب البيانات تقول اللوحة ذلك بدل أن تخترع.

المسارات: `/` لوحة · `/api/signals` JSON · `/api/health` فحص · `/narrative` نص عربي جاهز لتلغرام.

## التشغيل المحلي (بدون Cloudflare)

```bash
git clone https://github.com/jfjdjdieifne/copytrade-aggregator.git
cd copytrade-aggregator
pip install -e ".[dev]"

# 1) عرض كامل بلا إنترنت — يثبت أن المنطق سليم
python -m cta.cli demo

pytest -q

# 3) فحص الاتصال بالمنصات (يحتاج شبكة)
cp .env.example .env      # املأ التوكنات
python -m cta.cli doctor

# 4) بناء قائمة المراقبة من بيانات حقيقية
```

## النشر على Cloudflare

> 📱 **تربط تلغرام من الجوال؟** اقرأ [`README_TELEGRAM_AR.md`](README_TELEGRAM_AR.md) — ٥ خطوات، كل واحدة فيها علامة نجاح.
>
> 📱 **تنشر من الجوال؟** اقرأ [`README_DEPLOY_AR.md`](README_DEPLOY_AR.md) أولاً — فيه الخطوات بالترتيب وماذا تتوقع أن ترى.

### 1) المتطلبات
```bash
npm install -g wrangler
wrangler login
```

### 2) أنشئ بوت تلغرام
1. `@BotFather` → `/newbot` → انسخ التوكن
2. أرسل رسالة لبوتك، ثم خذ `chat_id` من `@userinfobot`

### 3) الأسرار
```bash
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put TELEGRAM_CHAT_ID
wrangler secret put TELEGRAM_WEBHOOK_SECRET   # أي نص عشوائي — يُتحقق منه في الـ webhook
wrangler secret put OWNER_TOKEN               # لحماية /kick و/refresh
```

### 4) اضبط `wrangler.toml`
```toml
[vars]
WORKER_URL = "https://copytrade-radar.<نطاقك>.workers.dev"
```

### 5) انشر
```bash
wrangler deploy
```

### 6) التهيئة الأولى (مرة واحدة)
```bash
curl -X POST https://copytrade-radar.<نطاقك>.workers.dev/boot \
  -H "x-owner-token: <OWNER_TOKEN>"
```
هذا يبني قائمة المراقبة ويسجّل الـ webhook.

### 7) تحقق
```bash
curl https://copytrade-radar.<نطاقك>.workers.dev/health
```
يجب أن ترى `watchlist` أكبر من صفر و`source_health` كلها `true`.

### قواعد المساعد (مهمة)

- **لا يخترع أرقاماً.** يستقبل حقائق JSON مُحسوبة مسبقاً ويُمنع من الحساب.
- **لا ينفّذ ولا يوصي بمال.** يشرح فقط.
- **لا يصمت أبداً.** إن فشل النموذج أو نفدت الـ neurons أو تأخّر، يرد **مُلقِّن حتمي** بالعربية من نفس الأرقام.

هذا التصميم مقصود: الأوامر اليومية لا تعتمد على توفّر نموذج، والمحادثة لا تعتمد على صحته.

## الحدود المعروفة (اقرأها)

1. **التأخير**: البيانات المجانية تصل متأخرة ثوانٍ إلى دقائق. بوابة الانزلاق (50 bps) تمنع الدخول المتأخر، لكنها لا تجعلك أسرع.
2. **الارتباط الخفي**: كشف «المحافظ التوأم» يعتمد على توقيت ≤30 ثانية + حجم متطابق. ارتباط أذكى (نفس المؤثر على تويتر) لا يُكتشف آلياً.
3. **البقاء على قيد الحياة**: الليدربورد يعرض الناجين. لذلك `outcomes.py` يقيس **بعد** النشر، لا على التاريخ.
4. **dYdX وGMX يحتاجان محافظ بذور**: لا ليدربورد متابعين عاماً فيهما.
5. **لم يُشغَّل حياً بعد**: كل الاختبارات على بيانات اصطناعية أو استجابات مُحاكية مطابقة لوثائق المنصات. **أول تشغيل حقيقي قد يكشف فروقاً في شكل الاستجابة** — لهذا `/doctor` موجود.
