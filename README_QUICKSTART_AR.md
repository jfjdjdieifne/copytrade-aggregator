# بعد نجاح البناء — ٤ خطوات

> الـ Worker صار منشوراً. هذا الملف يقول لك وين الرابط وشو تعمل بعدها.

---

## الرابط — وين ألاقيه؟

عندك **٣ طرق**، كلها بتوصل لنفس الشي:

### الطريقة ١ (الأسهل): من صفحة الـ Worker

أنت أصلاً بهالصفحة:
```
Workers & Pages → copytrade-aggregator → production
```
فوق بالصفحة في **رابط** أو **Visit** — اضغطه. أو انسخ النص اللي شكله:

```
https://copytrade-aggregator.<اسم-حسابك>.workers.dev
```

### الطريقة ٢: من صفحة التهيئة نفسها

أضف `/setup` لأي رابط عندك، والصفحة **بتقولك رابطك الصح**:

```
https://<أي-شي>/setup
```

بترجّع JSON فيه:
```json
"worker_url": "https://copytrade-aggregator.xxx.workers.dev",
"worker_url_source": "auto-detected",
"dashboard": "https://copytrade-aggregator.xxx.workers.dev/dash"
```

### الطريقة ٣: اللوحة بتعرضه لك

أي صفحة تفتحها من الـ Worker — رح تلاقي صندوق فيه:
- رابط الـ Worker
- رابط ربط تلغرام

---

## ✅ ما تحتاج تحط `WORKER_URL` أبداً

الكود صار **يكتشف رابطه بنفسه** من الطلب نفسه. وإذا كان `WORKER_URL` فيه
`<your-subdomain>` (النص المؤقت)، بيتجاهله ويستعمل الرابط الحقيقي.

**يعني:** لو حاطط `WORKER_URL` غلط أو نسيته — ما رح يكسر شي.

---

## الخطوة ١ — المتغيرات

**Settings → Variables and Secrets → Add** — اثنين فقط:

| الاسم | النوع | من وين |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | **Secret** | @BotFather → `/newbot` |
| `TELEGRAM_CHAT_ID` | Text | @userinfobot → `Id:` |

⚠️ **لا تحط `TELEGRAM_WEBHOOK_SECRET`** — إلا إذا بدك تدوّر عليه بعدين.

بعد الإضافة: **أعد النشر** (Deploy) لتنطبق.

> 🔴 **إذا كنت بعتّ التوكن بالمحادثة — اعمل `/revoke` أولاً** واستعمل الجديد.

---

## الخطوة ٢ — اربط تلغرام

افتح من متصفح الجوال:

```
https://<رابط-الـ-Worker>/setup
```

**النجاح:**
```json
"ok": true,
"registered_url": "https://....workers.dev/telegram",
"expected_url":   "https://....workers.dev/telegram"
```

الرابطان **لازم يكونوا متطابقين**.

**إذا فشل** — الصفحة بتقول السبب:

| تشوف | المعنى |
|---|---|
| `TELEGRAM_BOT_TOKEN is not set` | المتغير ما انحفظ، أو ما أعدت النشر |
| `last_error` فيه نص | تلغرام رفض — غالباً التوكن غلط |
| `registered_url` ≠ `expected_url` | في `WORKER_URL` قديم باللوحة — امسحه |

---

## الخطوة ٣ — اختبر

افتح تلغرام → بوتك → ابعت:

```
/help
```

**لازم يرد** بقائمة أوامر عربية.

إذا ما ردّ: افتح `/setup` مرة تانية وشوف `pending_updates` و`last_error`.

---

## الخطوة ٤ — شوف اللوحة الحيّة

```
https://<رابط-الـ-Worker>/dash
```

- **🟢 شريط أخضر** = الاتصال بالمنصات يعمل
- **🟡 أصفر** = لا اتصال — شوف `source_health`

---

## شو تتوقّع

| الوقت | المتوقع |
|---|---|
| أول دقيقة | `watchlist` يبدأ يعبي |
| أول ساعات | يمكن **ما يجيك ولا إشارة** — وهذا **صح** |
| عند إشارة | رسالة فيها العملة + الاتجاه + الستوب + الهدف |

**الصمت ليس عطلاً.** النظام مصمّم ينتظر اتفاق متداولين مستقلين — حدث نادر.
إذا جاك ٥ إشارات بأول ساعة، فهذا خلل مش نجاح.

---

## أوامر البوت

| الأمر | الوظيفة |
|---|---|
| `/help` | القائمة |
| `/latest` | آخر إشارة |
| `/watchlist` | المتداولون المراقَبون ودرجاتهم |
| `/why` | **ليش ما في إشارة** — أسباب الرفض |
| `/stats` | أداء الإشارات فعلياً |
| `/health` | حالة النظام |

---

## إذا صار خطأ بعد النشر

هذي المرة الأخطاء **رح تكون واضحة**، لأنها بوقت التشغيل مش بالتحقق:

**Cloudflare → Worker → Logs → Begin log stream**

وبعدها استعمل البوت. رح تشوف كل طلب وكل خطأ مباشرة.
