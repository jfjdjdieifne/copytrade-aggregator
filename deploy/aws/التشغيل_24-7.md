# التشغيل ٢٤/٧ — خطوات فعلية

## ١. جهّز التلغرام (٥ دقائق، مرة واحدة)

1. افتح تلغرام وابعت `/newbot` لـ @BotFather
2. سمّي البوت وخذ **التوكن** (شكله `123456:ABC-DEF...`)
3. ابعت أي رسالة للبوت، بعدين افتح:
   `https://api.telegram.org/bot<التوكن>/getUpdates`
   خد رقم `"chat":{"id":...}` — هاد هو **CHAT_ID**

## ٢. انسخ المشروع على السيرفر وأعطِ المفاتيح

```bash
git clone https://github.com/jfjdjdieifne/copytrade-aggregator.git
cd copytrade-aggregator
git checkout arena/4bff239f-copytrade-aggregator
cp .env.example .env
```

عدّل `.env` — هذَين الإثنين بس إلزاميين:

```
TELEGRAM_BOT_TOKEN=التوكن_من_البوت_فاذر
TELEGRAM_CHAT_ID=رقم_المحادثة
```

## ٣. جرّب قبل ما تسيبو شغال

```bash
python3 -m cta.cli doctor     # يشوف مين من المنصات بيرد
python3 -m cta.cli scan       # دورة بحث واحدة
```

## ٤. شغّلو ٢٤/٧

```bash
# الطريقة المضمونة: systemd (الملف موجود، بس يحتاج يتعبّى)
sudo ./deploy/aws/install.sh      # يعبّي المسارات ويركّب الخدمة
sudo systemctl status copytrade
sudo journalctl -u copytrade -f         # تابعوه
```

`install.sh` هو اللي يعبّي `__USER__` و`__REPO_DIR__` و`__PYTHON__` جوّه
`copytrade.service` — ما تعبيهن بإيدك، الملف القالب بيوهم systemd بصلاحيات
غلط بصمت.

أو بدون systemd:

```bash
nohup python3 -m cta.cli run --interval 60 > cta.log 2>&1 &
```

## ٥. شو تتوقع

- **أول دورة**: بتبني قائمة المراقبة تدريجياً (البرنامج بيمشي على
  المتداولين بشريحة صغيرة كل دورة عشان ما يستهلك الحصة المجانية)
- **بعد كم ساعة**: القائمة تكتمل وتبدأ العناقيد بالظهور
- **الإشارة** بتوصل هيك:

```
🔔 STRONG — ETH LONG
٤ متداولين من منصتين · ٨٩/١٠٠
دخول ٣٢١٠.٨ · ستوب ٣١٤٩.١ · هدف ٣٣٣٤.٥
R:R ١.٩ · المخاطرة ١٪
```

## ٦. إذا ما وصلتك إشارات

```bash
python3 -m cta.cli doctor                    # كل المنصات حمرا؟ شبكة/حظر
python3 -m cta.cli chat "كم متداول عندك؟"     # اسألو مباشرة
```

الحالة محفوظة بـ `state.db` — امسحو بس إذا بدك تبلش من الصفر.

---

## ليش كان في صمت قبل هيك

كان في خطأ واحد كبير: **إرسال التلغرام كان محطوط جوه بلوك `except`**
تبع الحساب الورقي. يعني الإشارة كانت توصل بس لما القيد الورقي يفشل.
بالحالة الطبيعية — القيد شغال تمام — ما كان يوصل ولا شي، وكل
العدادات بتقول إنو الدورة نجحت.

أربع مية اختبار كانوا بيمرو مع هالخطأ لأنو ولا واحد سأل: «هل وصلت
الرسالة؟». هالسؤال صار عندو ملف اختبارات لحالو: `tests/test_delivery.py`.

## تشغيل بلا شبكة (للتجربة بس)

```bash
SIM=1 ENABLED_SOURCES=sim,sim-beta python3 -m cta.cli run --interval 5
```

بيشغّل نفس خط الأنابيب على سوق مُفبرك. مفيد تشوف شكل الإشارات قبل
ما تتصل بالمنصات الحقيقية. **ما بتوصلك إشارات حقيقية منها** —
متداولين وهميين.

## روتينك اليومي (بعد ما تشغّلو)

النظام صار بيتابع **الفكرة** مو بس الإشارة. يعني كل صفقة إلها بداية
ونهاية، وهذول الرسائل اللي بتوصلك:

### ١. صفقة جديدة — هاد وقت تدخل

```
🟢 صفقة جديدة: SOL — شراء
قوة الإجماع: قوية جداً (90/100)

• متداولون مستقلون: 5
• المصادر: sim, sim-beta

• الدخول: 149.481
• الستوب: 145.784
• الهدف: 156.998
• العائد/المخاطرة: 2.0:1

سأتابع هالمتداولين وأقولك متى يخرجون.
```

### ٢. الإجماع يقوى — **ما تسوّي شي**

```
📈 SOL — شراء: الإجماع يقوى
• انضم 3 متداول جديد · صاروا 8
ما في شي تسويه — نفس الصفقة، صارت أقوى.
```

هاي أهم رسالة بالتحديث: إجماع تاني على نفس الفكرة **مو صفقة جديدة**.
بدونها كانت توصللك رسائل كتير على فكرة وحدة وتسكت القناة.

### ٣. المحترفون يخرجون — هاد وقت تطلع

```
🚪 ETH — بيع: المحترفون يخرجون
• خرج 3 من أصل 3 متداول
• نتيجتك الآن: +1.34R — ربح
• أعلى نقطة وصلتها: +1.37R (أعطيت منها 0.03R)

القرار لك: تخرج معهم أو تكمل على ستوبك.
```

**ليش ما بقلّك «أقفل هلأ»؟** لأنو هل خروجهم بيحمل معلومة فعلاً سؤال
تجريبي — المحاكي ما بيقدر يحسمو، والتجربة عليه أعطت نتيجة سلبية
(الخروج معهم كان أسوأ من التمسّك). فبأعطيك الأرقام والقرار إلك.

### ٤. السجل المُنسوب — هاد كيف تتعلّم

```
python3 -m cta.cli chat "شو أفضل منصة عندك؟"
```

كل صفقة مقفولة تتسجّل مع مصادرها وعدد المتداولين ونتيجتها بـ R.
بعد ١٠٠ صفقة النظام بيقدر يجاوب «أي منصة بتكسب؟».

⚠️ متوسط على ٣ صفقات مش إحصاء — كل متوسط بيوصل مع عدد الصفقات
اللي بني عليها.
