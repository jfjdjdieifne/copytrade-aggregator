# أول ٤٨ ساعة على أمازون

## قبل ما تسأل «ليش ما جاتني صفقات؟»

اقرأ هادي الأول، لأنو **الصمت إلو سببين**، والفرق بيناتن بيكلّفك أيام:

| | المعنى | التصرف |
|---|---|---|
| **السوق هادي** | بيراقب ١٤٠ محترف، وما في اتنين متفقين هلأ | انتظر — هاد صح |
| **العتبات ضيقة** | في إجماع بس ما بيعدّي البوابات | وسّع العتبة اللي باينة |

من برّا التنين شكلهم واحد: **صمت**. وما بتفرّق بيناتن إلا بالقياس.

## الأمر اللي بيجاوب

```bash
python3 -m cta.cli funnel
```

بيقولك بالظبط وين واقف:

```
── القمع ──
  قائمة المراقبة : 137
  مراكز مرئية    : 412
  محافظ بمركز    : 89
  عملات مرئية    : ARB, BTC, DOGE, ETH, SOL

── أقرب الإجماعات ──
  ❌ BTC LONG: 3 متداول (2 مصدر) · انتشار 12bps · تباعد 45د · عمر 12د
        ↳ عدد المستقلين 3 < 2          ← عدّي
        ↳ المحترفون 2 < 2              ← عدّي
        ↳ انتشار السعر 12bps < 50      ← عدّي
        ↳ تباعد الوقت 45د < 90         ← عدّي

📋 في إجماع جاهز: BTC LONG (3 متداول).
```

أو:

```
  ❌ ETH SHORT: 2 متداول · انتشار 18bps · تباعد 340د · عمر 20د
        ↳ تباعد الوقت 340د > 90

📋 أقرب إجماع: ETH SHORT 2 متداول، وقفو عند: تباعد الوقت 340د > 90.
```

التاني بيقولك: **الاتنين كانو صح بس دخلو متفرقين بـ ٥ ساعات**. هاد مو إجماع،
هاد اتنين تداولو نفس الفكرة بوقتين مختلفين.

## سيناريوهات أول ٤٨ ساعة

### ١. «٠/٤ منصة تستجيب» ← مشكلة شبكة

السيكيورتي غروب بيمنع الخروج. تأكد إنو الـ outbound مفتوح على ٤٤٣.

```bash
curl -s -o /dev/null -w "%{http_code}" https://api.hyperliquid.xyz/info
```

لو رجّع غير `200` أو `000`، هاد المشكلة — مو الكود.

### ٢. «قائمة المراقبة: ٠» ← البحث ما اشتغل

شغّلو كم دورة. البحث **متعمّد بيتمهل**: بيفحص شريحة صغيرة كل دورة عشان
ما يستهلك الحصة. أول ١٠ دورات بيبنو القائمة تدريجي.

### ٣. «قائمة المراقبة: ١٤٠، بس ما في إجماع» ← **هادي الطبيعي**

هاد يعني النظام شغال صح والسوق هادي. **ما توسّع العتبات عشان تجبر إشارات** —
هادي الطريقة الوحيدة المؤكدة تخسر فيها فلوس.

### ٤. «أقرب إجماع وقف عند تباعد الوقت» ← وسّع النافذة

التسعين دقيقة ضيّقة للمحترفين اللي بيحتفظو بمراكز أيام. جرّب:

```bash
CONVERGENCE_WINDOW_MIN=240 python3 -m cta.cli run
```

### ٥. «أقرب إجماع وقف عند انتشار السعر» ← وسّع التحمّل

```bash
ENTRY_TOLERANCE_BPS=120 python3 -m cta.cli run
```

## قاعدة واحدة

**ما تغيّر عتبتين بنفس الوقت.** غير وحدة، استنى ٢٤ ساعة، قيس. لو غيرت
التنين ما بتعرف أي واحد أثّر.

## شو تتوقع واقعياً

ما بعرف. وبصراحة: **ما حدا بيعرف قبل التشغيل الحقيقي**. المحاكي اللي
اختبرت فيه بيصحّح الميكانيك، مو الأفضلية — سوقو مشاة عشوائية وما بيتفاعل
مع المتداولين.

اللي بعرفو:

- ✅ الكود بيشتغل من أول دورة لآخرها (٤٦٨ اختبار)
- ✅ الرسائل بتوصل (دخول، تقوية، خروج)
- ✅ لو صار إجماع حقيقي، رح يوصلك
- ❓ **كم مرة بيصير إجماع حقيقي؟** — ما بتعرف إلا بالقياس

ممكن توصللك ٣ صفقات باليوم. وممكن وحدة بالأسبوع. وممكن ولا وحدة بأسبوعك
الأول. التلاتة محتملة، والفرق بيناتن هو بالظبط اللي `funnel` بيقيسو.

## بعد أول ١٠ صفقات

```bash
python3 -m cta.cli chat "شو أفضل منصة عندك؟"
```

السجل المُنسوب بيكون اجتمع عندو عينة. قبل هيك، أي «تحسين» هو تخمين.
