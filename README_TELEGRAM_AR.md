# ربط تلغرام — خطوة بخطوة (من الجوال)

> اقرأ هذا بالترتيب. لا تتخطَّ خطوة. كل خطوة فيها **كيف تعرف أنها نجحت**.

---

## أول شي: شو صار وشو لازم يصير

عندك هلق:

```
Cloudflare Worker  ──►  يجمع البيانات من منصات التداول
        │
        └──►  يرسل لك رسائل على تلغرام  ← هذا الجزء لسا مش موصول
```

**تلغرام ما بيعرف عن الـ Worker شي.** لازم نعرّفه: «كل ما حدا كتب لبوتك،
ابعث الرسالة لهذا الرابط». هذا الرابط اسمه **webhook**.

الخطوات تحت بتعمل هذا الربط. أنت بتعمل ٣ أشياء بس، والباقي صار جاهز بالكود.

---

## الخطوة ١ — أنشئ بوت (٢ دقيقة)

افتح تلغرام → ابحث عن **@BotFather** → أرسل:

```
/newbot
```

بيسألك:
1. **اسم البوت** — أي شي، مثلاً `رادار التداول`
2. **اسم المستخدم** — لازم ينتهي بـ `bot`، مثلاً `my_radar_bot`

بعدها بيردّ برسالة فيها سطر شكله:

```
123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
```

**☝️ هذا هو `TELEGRAM_BOT_TOKEN`.**

> ✅ **نجحت إذا:** شفت التوكن. احفظه بمكان آمن (مو بالمحادثة).

---

## الخطوة ٢ — جيب رقم محادثتك (٣٠ ثانية)

افتح تلغرام → ابحث عن **@userinfobot** → اضغط **Start**.

بيردّ بشي شكله:

```
Id: 987654321
```

**☝️ هذا هو `TELEGRAM_CHAT_ID`.**

> ✅ **نجحت إذا:** شفت `Id:` ورقم.

---

## الخطوة ٣ — حطّهم بـ Cloudflare (٢ دقيقة)

روح لـ **dash.cloudflare.com** → **Workers & Pages** → اختر الـ Worker تبعك →
**Settings** → **Variables and Secrets** → **Add**

أضف **٣ متغيرات** فقط:

| الاسم | النوع | القيمة |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | **Secret** | التوكن من الخطوة ١ |
| `TELEGRAM_CHAT_ID` | Text | الرقم من الخطوة ٢ |
| `WORKER_URL` | Text | رابط الـ Worker، مثلاً `https://copytrade-radar.abc.workers.dev` |

⚠️ **مهم:** `WORKER_URL` **بلا** `/` بآخره.

⚠️ **لا تضف** `TELEGRAM_WEBHOOK_SECRET` — اتركه فاضي. (لو حطيته بدون ما يتسجّل
عند تلغرام، البوت بيموت بصمت.)

بعد الإضافة: **Deployments** → أعد النشر (أو اعمل Deploy جديد) لتنطبق المتغيرات.

> ✅ **نجحت إذا:** المتغيرات الثلاثة ظاهرة بالقائمة.

---

## الخطوة ٤ — اربط (ضغطة واحدة) 🎯

افتح هذا الرابط **بمتصفح الجوال** (بدّل `<worker>` برابطك):

```
https://<worker>/telegram/setup
```

بتطلع لك صفحة JSON. ابحث فيها عن:

```json
"ok": true,
"registered_url": "https://<worker>/telegram",
"expected_url":   "https://<worker>/telegram"
```

> ✅ **نجحت إذا:** `ok: true` و`registered_url` **مطابق** لـ `expected_url`.

**إذا طلع `ok: false`** — الصفحة بتقولك السبب بالضبط:

| ما تراه | المعنى | الحل |
|---|---|---|
| `TELEGRAM_BOT_TOKEN ... not set` | المتغير ما انحفظ | أعد الخطوة ٣ |
| `registered_url` مختلف عن `expected_url` | `WORKER_URL` غلط | صحّحه وأعد الخطوة ٤ |
| `last_error` فيه نص | تلغرام رفض الرابط | تأكد الـ Worker شغّال: افتح `/health` |

---

## الخطوة ٥ — اختبر

افتح تلغرام → بوتك → أرسل:

```
/help
```

> ✅ **نجحت إذا:** ردّ بقائمة أوامر عربية.
>
> ❌ **إذا ما ردّ:** افتح `https://<worker>/telegram/setup` مرة ثانية،
> وشوف `pending_updates` و`last_error`.

---

## شو المفروض يصير بعدها

| الوقت | المتوقع |
|---|---|
| أول دقيقة | `watchlist` بيبدأ يعبي من Hyperliquid |
| أول ساعات | يمكن **ما يجيك ولا إشارة** — وهاد **صح** |
| عند إشارة | رسالة فيها العملة، الاتجاه، الستوب، الهدف، وسبب الثقة |

**لا تتفاجأ بالصمت.** النظام مصمّم يصمت لحد ما يتفق متداولان مستقلان على نفس
الصفقة. إذا جاك ٥ إشارات بأول ساعة، هاد خلل مش نجاح.

---

## أسئلة سريعة

**هل أقدر أستعمل بوت ثاني؟**
نعم — بدّل `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` وأعد الخطوة ٤.

**كيف أغيّر التوكن بعدين؟**
نفس المكان بـ Cloudflare → Edit → Deploy → أعد الخطوة ٤.

**هل أحد غيري يقدر يستعمل بوتي؟**
لا. الكود صار يرفض أي محادثة غير `TELEGRAM_CHAT_ID`، ويرد:
«هذا البوت خاص».

**هل التوكن بيطلع بالرابط؟**
لا. `/telegram/setup` ما بيطبع التوكن أبداً — بس الرابط المسجّل وحالة النجاح.

**إذا خرب شي، وين أشوف السبب؟**
Cloudflare → Worker → **Logs** (Real-time). أو `/telegram/setup` مباشرة.

## ما تم إصلاحه في هذا الفرع

| العطل | كان | صار |
|---|---|---|
| الـ secret | يُفحص عند الاستقبال ولا يُسجّل عند تلغرام → **403 لكل رسالة** | يُسجّل ويُفحص من نفس المتغير |
| الربط | يحتاج `POST /boot` (مستحيل من الجوال) | `GET /telegram/setup` بضغطة |
| الأمان | أي شخص يقدر يحكي مع البوت ويستهلك الـ AI | محادثة المالك فقط |
| التشخيص | فشل الربط صامت | يرجّع الرابط المتوقع/المسجّل والخطأ |
